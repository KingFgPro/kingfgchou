# 更新日志

## V10.5 (2025-04-01)

### 新增
- 新用户初始积分调整为 50
- 小礼包 / 大礼包 改版为 幸运袋 / 宝箱
- 幸运袋、宝箱开出积分的概率大幅降低（10% / 8%）
- 新增"碎片礼盒"道具，可直接开出 10 个碎片
- 新增"双倍积分卡"道具，下一次抽奖积分翻倍
- 新增"免抽券"道具，下一次抽奖不消耗积分
- 新增"幸运硬币"道具，下一次抽奖必出稀有奖励

### 优化
- 幸运袋开出内容：碎片 / 幸运符 / 时间沙漏（90%），少量积分（10%）
- 宝箱开出内容：碎片 / 幸运符 / 时间沙漏 / 神秘宝箱（92%），少量积分（8%）

## V10.0 (2025-03-01)

### 新增
- VIP / SVIP 套餐全面升级：天卡、周卡、月卡、季卡、半年卡、年卡、连续包月、连续包年
- 新增"每日折扣"功能：管理员可设定每月几号打几折
- 折扣对抽奖消耗、商城商品、VIP 套餐全部生效
- 用户端显示"今日折扣"提示

### 优化
- 抽奖消耗、商城价格、VIP 价格自动按折扣计算
- 后台新增"折扣"标签页，支持增删折扣

## V9.5 (2025-02-01)

### 新增
- 新增"碎片"系统，抽奖可获得碎片
- 新增"碎片兑换"功能：
  - 1,000 碎片 → 50 积分
  - 10,000 碎片 → 7 天 VIP
  - 100,000 碎片 → 7 天 SVIP
- 奖池新增"幸运符"道具，使用后下一次必出积分类奖品
- 奖池新增"时间沙漏"道具，使用后今日抽奖次数清零
- 奖池新增"扣积分"负面奖品（-20 积分）
- 侧边栏新增"碎片"入口

### 优化
- 抽奖积分权重整体降低，稀有奖励更珍贵
- 背包预览显示碎片数量
- 版本历史新增 V9.5
