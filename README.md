# 🎁 抽奖系统 V10.5 功能简介

# 一个纯前端的抽奖小工具，双击网页就能玩，数据存在你自己的浏览器里。

---

## 🎰 抽奖玩法

### 抽奖方式
- **单抽**：消耗 10 积分
- **10 连抽**：消耗 90 积分（比单抽省 10 积分）
- **查看全部奖池**：能看到每个奖品和对应概率

### 奖池内容
- 奖池里有很多种奖品，按概率随机

| 类型 | 举例 |
|------|------|
| 积分奖励 | +10、+50 积分 |
| 扣分惩罚 | -20 积分（抽到会扣分哦） |
| 碎片 | 集齐可兑换好东西 |
| 幸运袋 | 随机开出道具或碎片 |
| 宝箱 | 高级版幸运袋 |
| 神秘宝箱 | 必出稀有奖励 |
| 幸运符 | 下一次必出积分类奖品 |
| 时间沙漏 | 今日抽奖次数清零 |
| 双倍积分卡 | 下一次积分翻倍 |
| 免抽券 | 下一次抽奖不花积分 |
| 幸运硬币 | 下一次必出稀有奖励 |

---

## 🧩 碎片系统

### 碎片兑换
- 抽奖可以抽到**碎片**，攒够了就能兑换：

| 碎片数量 | 兑换奖励 |
|----------|----------|
| 1,000 | 50 积分 |
| 10,000 | 7 天 VIP |
| 100,000 | 7 天 SVIP |

- 背包里碎片数量一目了然，攒够了就能一键兑换。

---

## 🛒 兑换商城

### 道具列表
- 用积分买道具，每个道具有不同用途：
- **幸运袋**：100 积分，开出道具或碎片
- **宝箱**：300 积分，开出高级道具
- **神秘宝箱**：800 积分，必得稀有奖励
- **幸运符**：下一次必出积分类奖品
- **时间沙漏**：今日抽奖次数清零
- **双倍积分卡**：下一次积分翻倍
- **免抽券**：下一次抽奖免费
- **幸运硬币**：下一次必出稀有奖励
- **碎片礼盒**：打开直接得 10 个碎片

---

## 🎒 我的背包

### 背包功能
- 查看所有道具及数量
- 直接使用道具
- 碎片一键跳转到兑换界面

---

## 👑 VIP / SVIP

### 套餐类型
- VIP 和 SVIP 各有 8 种套餐可选：
- 天卡、周卡、月卡、季卡、半年卡、年卡
- 连续包月、连续包年（自动续费标识）

### 每日福利
- 开通后**每天登录**会送额外积分：
- VIP 每日 +20 积分
- SVIP 每日 +50 积分

---

## 🎟️ 兑换码

### 使用方式
- 输入兑换码即可领取积分或会员
- 每个码每人只能用一次
- 支持积分、VIP、SVIP 三种类型

---

## 📢 公告弹窗

### 弹窗模式
- 打开页面时会弹出最新公告，可能是：
- 纯文字通知
- 纯图片展示
- 图片 + 文字

### 关闭方式
- 点"确定"即可关闭，不错过任何重要消息。

---

## 📜 版本历史

### 查看入口
- 在侧边栏"关于"里可以查看所有版本更新记录
- 从 V9.0 一直到现在，每次新增了什么功能都记得清清楚楚。

---

## 💡 小提示

### 玩法建议
- 奖池里积分奖励概率**很低**，大多是道具和碎片
- 稀有道具用好了能让抽奖更划算
- VIP / SVIP 不只能提速，每天登录还能白嫖积分
- 碎片别浪费，攒够 10 万换 7 天 SVIP 超值

---

## 🎮 怎么开始玩

### 快速上手
- 1. 打开网页
- 2. 注册一个用户名（不需要密码）
- 3. 系统自动送 50 积分
- 4. 点击"开始抽奖"就能玩

### 祝你好运
- 祝你好运，抽到终极大奖！🎉
